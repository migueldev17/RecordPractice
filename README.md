# RecordPractice 🚀

Repositorio dedicado al aprendizaje y práctica de la programación con **Ruby**, enfocado en dominar los conceptos clave antes de avanzar al framework **Ruby on Rails**.

## 📁 Estructura del Proyecto

* **`Ejercicio/`** 📘: Contiene archivos conceptuales (`ejercicio1.rb`, `ejercicio2.rb`, etc.) con explicaciones, teoría y las bases que vamos aprendiendo.
* **`Prueba/`** 🧪: Contiene los retos de código y prácticas autónomas (`prueba1.rb`, `prueba2.rb`, etc.) para validar el conocimiento adquirido.

---
## 📝 Bitácora de Aprendizaje

## ⚙️ Cómo ejecutar los archivos

Para probar cualquiera de los scripts, abre tu terminal (Git Bash o la integrada de VS Code) y ejecuta:

```bash
# Para ejecutar un concepto
ruby Ejercicio/ejercicio1.rb

# Para ejecutar una prueba
ruby Prueba/prueba1.rb
```
